# Release 0.3.0

An AI opponent for the Gwent public beta (client 0.9.24.3.432), played in the game's Practice mode. Release 0.3.0 adds a trained value network that judges positions from round 2 on.

**Wins 56% of the points against release 0.2.0 (95% range 52% to 60%), that is +40 Elo (+12 to +68), over 490 games (245 seat-swapped pairs) at 6,000 simulations a move, 13 October 2026.**

## What's new

- **A trained value network from round 2 on.** The AI looks ahead to the end of the current round, then judges each position as a chance to win the match. From round 2 on, a trained neural network does this judging. In round 1 a simpler scorer from 0.2.0 still does it. The network adds about 7% to the time of one decision at equal simulations (1,000 simulations a move, 120 pairs, 12 Oct 2026). The think time is the same, and search, belief model and settings are unchanged.
- **The AI decides only after the game has applied a card's pending actions.** Before, a card effect that still had actions waiting (a duel followed by a forced pick, for example) could make the AI decide from a position its search workers could not replay.
- **Card tables with Windows line endings are accepted.** The AI no longer rejects them after a Windows editor or checkout changed the line endings.

## How it compares

| Setting | Games | Points won | Elo (95% range) | Date |
|---|---|---|---|---|
| 6,000 simulations a move, against 0.2.0 | 490 (245 pairs) | 55.7% (51.7% to 59.7%) | +40 (+12 to +68) | 13 Oct 2026 |
| 1,000 simulations a move, against 0.2.0 | 240 (120 pairs) | 60.8% (55.6% to 66.1%) | +76 (+39 to +116) | 12 Oct 2026 |
| 6,000 simulations a move, against 0.2.0 (earlier test) | 240 (120 pairs) | 54.8% | +33 (-10 to +73) | 12 Oct 2026 |
| 6,000 simulations a move, against 0.3.0 with the value network switched off | 80 (40 pairs) | 56.9% (46.3% to 67.4%) | +48 (-25 to +126) | 12 Oct 2026 |

How we measure: the same deal is played twice, once from each seat, so luck of the draw cancels out. Both sides get the same fixed number of simulations a move and each uses one search tree. We count points, not wins, because a tied game counts half.

490 games is a small sample, so the range is wide. The 95% range is the span of strength gaps that fit these games; more games would narrow it. The 120-pair test at 6,000 simulations is less favourable, and its range includes 0. These tests changed only the value network; the other two changes above were not in them.

These are head-to-head results between releases, not a rating against people. An earlier version won 30 of 30 games (95% range 88.6% to 100%) against the game's built-in AI, at the built-in AI's own thinking time, with the same strong 2018 decks on both sides, 7 Oct 2026.

This is still an early release. It punishes mistakes and experimental play, and a strong player with a deck they know well can beat it.

## Verify your build

Setup generates the card tables from your client and prints this line:

```text
card table: sha256 db0dbb0424c3e29b
```

The same value means your client matches the one this release was measured with. When the game starts, the loader's log (`MelonLoader/Latest.log` in the client folder) shows the AI's start line, ending with:

```text
policy prior pol2 sha256 b4acc8471aa94298
```

The same value means the AI uses the network that was measured. The value network ships as one file, `data/model/fta.vnet` (SHA-256 beginning `f32c9e976cff5ff4`), with its card columns zeroed; the AI fills them from your own card table when it loads, as it does for the policy network.

## Known limits

- It looks ahead within the current round. Later rounds come from the value network's score (the simpler scorer's in round 1).
- It thinks about 10 seconds on a normal move and up to 30 on a hard one, on `min(6, cores - 2)` helper processes. Fewer cores make it weaker.
- Tested on Linux (Fedora 44). Windows 11 was tested for 0.2.0 and macOS (Apple silicon) for 0.1.0; this release has not been run on either.
- On macOS, turn premium cards off in the game's settings: their animations do not render on a Mac, and the cards show no art.
